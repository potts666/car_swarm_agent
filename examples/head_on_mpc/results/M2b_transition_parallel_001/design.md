# M2b 候选衔接与封存同步设计

版本：sealed-jacobi-v1。历史 M2b/M2b_stage1 包只读。源版本见 current_source_version.txt 与正式 formal_freeze.json。

每车私有 Actor 持有一辆车的 Agent、队列、已提交参考输入和独立检查缓存。父进程只传递公开 DDS 解码消息、同轮资源上下文和提交屏障；优化器的诊断正文只用于记录。每车 QP 维数上限仍为 32/64，不调用联合求解或在线完整未来门禁。

一周期：实际快照→真实 DDS 公开报告→本车工作副本阶段准备→资源拟许可（如需，再从实际副本准备）→按模式／参考生成起始预测→一次批量投递→封存四个计划 ID 与轮号→四个局部计算→所有计算结束后批量最终预测投递→四端独立组合检查→四 ACK→全部首输入暂存→同版本提交广播→一次离线执行决定→四端激活。

S-J 与 P-J 都有四个持久子进程。S-J 依次调用本车计算，但在全部结束前不把本轮 final 送给任何后车；P-J 同时发起本车计算。两者只改变执行后端。计算跨度取各子进程 monotonic_ns，不把 DDS 线程数当作并发证据。DDS 为每个接收端一个定向可靠主题；一批先发布再按集合收齐，仍发送稠密公开轨迹。

初始化／切换／停车参考激活：从自己的真实状态、原有转向队列或参考 QP 重新生成。适用性记录 mode/index/停车激活与步数/速度上限/段末/授权。适用且检查合格时才移位上次实际提交的预测。阶段或参考不适用时清除工作副本的热启动；实际提交前不改已提交缓存。跨段姿态守卫采用位置范数 ≤0.005 m、航向误差 ≤0.003 rad；位置范数球内含于原每轴 ±0.005 m 的 QP 末端盒，是明确新增的保守充分条件，不能说与原盒等价，不重置状态。拒绝直接丢弃副本，不推进队列或提前 WAIT。

公开候选检查声明范围是动力学、道路、车身、权限、当前固定输入或部分标量进度／速度／末端行。它不是完整局部 OCP 证书；未覆盖当次所有线性化、走廊、信赖域和耦合行。参考热启动是另一份已提交参考输入的移位，允许初值不可行，不与公开 seed 混称。

本轮先冻结最大一轮同时更新；不存在按已知 cycle/名字追加轮数的分支。如局部或组合拒绝，则记录并零提交。代码有显式统一下一轮接口，但正式配置不启用，不能解释成已验证的多轮算法。

提交语义限于冻结时钟的离线模拟：四端先在私有 pending 副本验证并积分首输入，全部就绪且消息送达后才写入一条包含四车的 actual 执行记录。执行决定之前的失败零提交；决定之后的进程失效不能追溯撤销已执行周期，随后运行失败。此屏障不证明真实异步网络下的故障原子性或实车停车安全。

0.5 s 保留为每车计算调用预算，合计起始候选构造、本端预检查和本车优化；IPC／DDS／最终检查／认可／提交计入整周期，并另报 200 ms 目标。没有用四车 CPU 总和冒充整轮墙钟。启动、发现、关闭、导出及离线审计各自列出。缓存计数覆盖公开计划接收／封存检查和 ACK 内四次检查，起始候选构造检查单列于 candidates，不声称计到所有内部几何函数。

身份通过固定物理角色到公开 ID 的双射解释。内部队列方向及 FIFO 平局次序仍用物理角色；公开报告、轨迹、ACK、提交和日志均采用公开身份。重命名改变注册与启动顺序，绝不按改名推断方向。
