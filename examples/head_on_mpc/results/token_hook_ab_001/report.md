# 小型既有数值实验：token hook 关闭/开启实测

日期：2026-11-02。结论：**本次短任务没有省 token。** 开启 hook 后，主模型加自动审批的记录量从 **37,772** 增至 **38,188**，增加 **416（1.10%）**。这不是费用或订阅扣减的比较。

## 案例与对照

复用 `test_entry_bicycle.py` 中三个既有 RK4 数值检查：静止转向、入湾/返回连续性、跨零曲线运动。它们实际调用已有自行车积分、控制原语和相关断言；不是完整闭环任务，也未调用在线 QP。原先考虑的 M2b 冻结停车 QP 需要已清理的临时 OSQP 环境，因此未运行、未安装依赖。

两臂从新短会话开始，模型 `gpt-6.1-sol`、推理 `medium`、相同 cwd、相同 prompt、相同数值 shell 命令、单线程 OpenBLAS；只用命令行临时关闭/开启 hooks。两臂均保持自动审批，并对已确认无法启动的默认 bwrap 请求相同的正常审批路径。没有写信任哈希或改变全局权限。顺序固定为关闭→开启，单对测量，每臂120秒上限；未增加重复以追求有利结果。

## 为什么没有节省

开启组的会话记录确认注入了一次 `Token-efficient execution` 启动规则，专属状态显示 `covered_tool_events=1`、`notes_sent=[]`、`wait_like_events=0`。关闭组无规则注入、无专属状态。两组都只需一次工具执行和一次最终答复，没有长命令监看、重复等待或大输出；hook 没有减少模型参与次数，只增加了提示上下文。主模型输入增加405与这个机制相符，但不能把全部416精确因果归给提示：审批输出和生成的理由文本也有变化。

开启组墙钟略短，token却略高，进一步说明单次程序/会话耗时不等于 token。缓存输入差异也不能折算费用或额度下降；输入已含缓存、输出已含推理，子项不再加算。

**适用结论：该全局启动提示在这种极短任务上有可见固定开销，不能宣称对所有任务都省 token。** 这组没有检验长任务中的等待提醒、驱动自动推进、旧长上下文拆分或归档复用收益。若后续调整，可考虑减少普通短任务的启动注入、保留必要时的一次提醒；本次未修改 hook 来改变已测结果。

## 证据、失败与成本边界

- `manifest.json` / `prompt.txt`：配置、相同 prompt、准确命令、开始结束时间及源文件哈希；被纳入冻结的源文件前后相同。
- `before.events.jsonl` / `after.events.jsonl`：CLI实际返回的会话ID和总 usage；`*.answer.txt` 是最终答复，测试通过另由原始工具输出核验。
- `comparison.json`：两臂及试运行的主模型/审批用量、精确来源、hook状态、原始测试小输出。
- `usage_increments.json`：定点读取匹配根会话和新建关联 guardian 的逐响应有效增量；每条均与累计差值一致，无重复响应。逐字段求和与CLI总 usage一致。记录数不称HTTP请求数。
- `comparison.csv`：主模型/审批分列的整数原值，含所有试运行。

首次试运行两臂均因默认沙箱启动失败，运行测试数为0，主模型分别记录30,124及30,532 token，未进入成功对照。它们原样保留在 `pilot_sandbox_failure/`，不混入成功两臂。CLI进程退出码0只说明模型正常结束，不代表测试通过；试运行最终答复及工具错误明确为FAIL。

四个受测会话（含失败试运行）的已识别主模型/审批合计 **136,616 token**，成功对照两臂合计75,960，失败试运行60,656。本次主对话的选择案例、准备、分析、报告与工具审批成本**没有计入**上述数值；不能把136,616当成整项工作的全部模型成本，也不能把它隐藏成“优化节省”。原始运行器路径断言还曾在任何模型调用前失败一次，随后修正，未产生受测模型 usage。

本机另有两臂共同出现的已有 superpowers 插件清单解析警告，未修改插件；数值检查实际通过。一次配对、顺序固定和共享缓存条件不足以给出统计置信区间或普遍节省率。没有重跑大实验，没有改原数值代码、历史实验包、原审计或已安装 hook。

复算入口：`python3 examples/head_on_mpc/results/token_hook_ab_001/analyze.py`。它仅按本目录四个会话ID与时间边界读取对应会话及关联新建审批，不启动模型或仿真。`run_comparison.py` 是实测驱动，拒绝覆盖已有 manifest；再次运行会产生真实模型用量，本次无需重跑。
