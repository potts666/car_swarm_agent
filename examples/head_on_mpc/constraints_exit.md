# 完整退出实验：终端与硬路径约束

适用 `scripts/run_exit_screening.py`。动力学和 `solve()` 来自 `head_on_core.py`；不修改原死锁复现入口的默认设置。原复现 `run_deadlock.py` 没有开启道路纵向优化约束或终端零速度；本轮与上轮对照统一开启它们。

纵向模型为精确零阶保持双积分：`x(t)=x0+v0*t+0.5*a*t²`、`v(t)=v0+a*t`。每 0.4 s 执行第一个加速度，预测 16 步共 6.4 s，每步 4 个样本。A 朝 +x，B 朝 −x，负/正全局速度分别表示 A/B 倒车。代价权重沿用位置 0.6、速度 0.4、加速度 0.15、加速度变化 0.2；它们是软代价，不能当成硬约束。

|类别|实际约束|实现与范围|
|---|---|---|
|优化终端|预测末端 `v(T)=0`|`terminal_stop=True`，用正反两个线性不等式实现；数值验收容差 1e−5|
|优化终端位置|**没有** `x(T)=目标` 或终端目标邻域约束|目标位置通过软代价和下述全路径不越过目标约束作用；单个预测末端停车不代表已完成退出|
|优化终端集合/代价|没有不变终端集、专用终端代价或递归可行性证明|不能据此宣称下一周期必可行|
|优化硬路径：速度|`−2 ≤ v(t) ≤ 2 m/s`|每个预测细采样点；允许双向速度，未开启旧版按目标方向限制速度|
|优化硬路径：加速度|`−a_max ≤ u[k] ≤ a_max`|每个控制段恒定；扫描对称上限 0.5/1 m/s²，无 jerk 硬约束|
|优化硬路径：目标不越界|`d*(x(t)−target) ≤ 1e−7`，`d=sign(target−x0)`|每次求解按当下目标方向确定；是全路径硬约束，不是终端等式|
|优化硬路径：纵向道路|`xmin+L/2 ≤ x(t) ≤ xmax−L/2`|每个预测细采样点，车长 L=4.7 m；不包含横向退让区并集几何|
|优化硬路径：邻车|前车 `x_peer−x ≥ L+margin`；后车 `x−x_peer ≥ L+margin`|margin=0.5 m，纵向重叠时保持中心距 ≥5.2 m；退让车对静止等待车规划，等待车再针对退让候选求解|
|完整路径验收：车身道路|全车身位于主路或退让区，且纵向位于全局道路边界|`inside_road()`，对初值、整个预测与执行轨迹每个样本检查；是生成后拒绝条件，并非 SLSQP 内部横向约束|
|完整路径验收：车身间距|`max(abs(dx)−L, abs(dy)−W) ≥ 0.5−1e−5 m`|W=2 m；检查配对的整段预测和实际执行样本；比旧实验的 0.08 m 执行验收阈值严格|
|完整路径验收：等待|等待车相对初始位置偏差 ≤0.01 m、速度 ≤0.01 m/s、横向位置为零|等待车仍实际求解并积分，不强制覆盖控制或重置状态|
|完整路径验收：其余|数值有限、速度与加速度满足上限；所有执行求解被接受|任何一次失败，整条候选不通过；预测安全不能代替实际执行检查|
|退出终态|退让车距退让目标 ≤0.08 m、速度 ≤0.025 m/s，且横向占用变化结束、到达 y=3 m；等待车仍静止|最多 100 s；要求整个退出通过检查，不只检查最后一个状态|

退出分为“沿主路倒车至入口外退让区”和“停车后按预设 6 s 横向占用曲线进入区内”两段。横向位移使用既有五次平滑曲线；没有自行车模型、转角/横向加速度约束或转向可达性证明。预测的末端零速度只约束纵向速度。

两个候选均从同一份安全静止初值重新生成，不把第一条结果作为第二条初值。固定 A 与筛选基线共享两条完整候选、相同模型/约束/每次 120 次迭代上限。筛选只采用整个退出成功的候选，按退让距离较短选择；两条均失败则不分配角色。固定 A 始终选 A，其候选失败时记失败，不代入未经检查的控制。两种基线都不在退出中途切换角色。

逐周期预测和执行采样覆盖整条退出，但离散样本不构成连续时间安全证明。求解拒绝只表明当前数值求解未被接受，并不证明数学上不可行。退出成功也不代表之后通行、回归或双车任务完成。
