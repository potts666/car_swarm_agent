# curve_joint_001 结果

通过：四臂 × 连续两轮 × 两个独立本车 worker，共 16 次正式尝试，全部 Solved、证书受理。每轮执行首拍后四车实际活动；第二轮使用各臂自身真实后继，未复用首轮预测状态。

共同首源为第 32 拍 A1 弯道与 A2 直线运动。32 拍窗口含加减速、停车转向与第二段曲率，使用 C4–C21 实际分段变分与有理加权矩；不套用常速圆弧示例。非零方向 c_cert≈0.569641，所用量化步幅 1e-5，逐行允许步幅下界约 1.33407e-4；方向完整后续已认证。

比较口径：下表均为候选减同源锚点，ΔJE=JE_new−JE_anchor、Δs=s_new−s_anchor、ΔF=ΔJE−lambda·Δs。为便于四臂横向比较，统一评估 F=JE−lambda·s（lambda=1 U_J/m）；E 臂实际优化目标仍是 JE。ΔJE/ΔF 为负表示改善，Δs 为正表示推进增加。

代价单位 U_J 是本实验原目标的归一化输入平方×秒，不是焦耳，也不是百分比；表中 ΔJE、ΔF 均为绝对差值。输入按既有尺度归一化，JE=h·sum(uᵀRu)，R=I。百分比单列，分母为同一行两辆车锚点窗口 JE 之和。进度单位为 m。数值表为区间中点的舍入显示；外向上下界及精确有理 ΔJE 保存在 tradeoff_summary.csv；Δs 区间包含零时表中显示 ≈0，不将区间中点残差当作有效推进。
