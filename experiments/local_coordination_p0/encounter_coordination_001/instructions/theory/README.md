# 自主DMPC剩余接口：本轮交付说明

日期：2026-11-14。版本AUT-DMPC-v1。

## 本轮完成的理论工作

完整证明见`完整证明.md`，便携包中对应`theory.md`。本轮按明确的初态与地图条件给出：

1. 从地图连接、初始/目标占用生成DAG，在线构造第一份有限完成策略；循环占用可采用有空闲缓冲端点的第二种构造。
2. 通过完整占用外扩登记、时间区间和版本事务证明局部信息发现覆盖全部潜在交互。
3. 以真实尾段构造可继承相位接收域，证明保留锚点的每轮局部SOCP有解。
4. 仿射增量量化格精确保留终端等式，并附误差界。
5. 将在线改合同、两层回退、有限活动选择及完成期限统一到总定理。
6. 对具有严格裕量的策略类，给出逐级细化候选的分辨率覆盖证明；在线算法仍保留有限预算。

初始化定理适用于Omega_DAG或Omega_BUF，定义与构造在正文第3—4节。它们将原先的“给定完成策略”推进为从可检查道路、端点和连接条件生成完成策略。

## 当前地图下一步怎样进入

首先用既有地图对象检查：每车可达连接、初始/目标端点安全、DAG边及拓扑；若有循环，再检查可用缓冲端点与避开其他停车域的连接。结果决定采用哪种初始化构造。

随后核对占用索引覆盖、永久目标占用、事务闭包及保留锚点编译。该步骤属于数学条件具体认证，利用解析、区间和有限图即可完成。控制实验再验证实现、实际多车更新及计算成本。

原001/002工程与控制器未改写，本轮未运行新数值求解。10类检查为精确示例和代数/逻辑核对；正文证明承担一般结论。当前地图是否落在两个初态集合，仍需以其实际域与连接证书判定。
