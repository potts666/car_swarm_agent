## 4. C0-2：最小修复路线与验收

首选保持原物理可行集的等价变量/行/锥表示，分别平衡输入、t、s及目标的尺度。若单纯缩放仍受限，可为每个二次行采用等价旋转锥表示；先代数验证新旧表示，再比较数值表现。固定依赖与Solved策略沿用。

边界点舍入问题采用预先设计的**内缩**或已有有限回退，保留严格有理行验收。内缩量须从输入量化误差推导，并记录损失的可行域。

对原行

\[
f(d)=g+a^Td+\epsilon\|d\|_2+\tfrac12H_r\|d\|_2^2,
\]

64维每分量最近舍入量子q=1e-12时，舍入差满足e_q≤4q。若原增量范数≤rho，取

\[
\eta_r=(\|a\|_2+\epsilon+H_r\rho)e_q+\tfrac12H_r e_q^2
\]

即可上界该行由舍入引起的增量。以认证上界计算eta，预留f(d)≤−eta，并对信赖球预留e_q。系数转浮点和锥转换的数值误差另外分析，最终仍用原有理行逐条检查。

检查内缩后的零锚点：已有零余量物理行逐行处理，采用可证的精确网格/定向舍入或保留原行加有限回退，说明误差界。为每条实际使用的舍入规则给出误差界与测试。候选通过条件保持Solved、原锥行、物理行、真实前缀、盒、K、后继域、预算和共同提交。

最多比较两种预登记的修复变体；每变体最多三个参数配置。单解5秒、300迭代、单阶段180秒；量化回退最多1、1/2、1/4。达到上限交付诊断与未通过项。

先对归档同一锚点验证，再对两个接口各运行一条实际闭环。冻结同一设置，并在ZG/ZL上回归各一个接口，确认修复后的配置对三种方法一致。

## 5. C1：精确的2米20→11拍例

初末状态：x从0到2米，y=psi=delta=0，初末v=1/2；h=1/5。直线路段足够宽、同伴静止并满足净空。基准20拍a=omega=0。

新输入：前5拍a=3/4，中间1拍a=0，后5拍a=−3/4，全程omega=0。精确ZOH关系：

\[
v_{k+1}=v_k+ha_k,\qquad
x_{k+1}=x_k+hv_k+\tfrac12h^2a_k.
\]

以Fraction或SymPy计算：终点x=2，末速1/2，最大速度5/4，时间20h=4秒和11h=2.2秒，节省9拍/1.8秒。新加速度能量h∑a²=9/8，旧能量0。初末五状态、每拍输入界及连续车身净空逐项核对。

两个分支绑定同一合法后续。验收按完成时间优先允许新分支能量增加，次级能量仅在相同时长/相同后续时间下比较。独立验收重算实际拍数和终点。

该例用于接入正确性；地图效果由C2记录。
