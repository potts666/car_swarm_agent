# Bounded execution

1. Freeze task inputs and inventory actual 001/002/region003 sources, gates,
   selected identities and preserved hashes (zero solver calls).
2. Construct endpoint/edge geometry and ZOH certificates; derive dependency
   graph and DAG/BUF conditions. Persist each failed condition before changing
   the shared generator, then rerun its regressions.
3. If a map condition passes: generate two request-dependent initial plans,
   compute B0, independently replay complete policies, then compare history.
4. Audit occupancy intents, closure, phase receivers and quantization identities;
   execute copied-branch negative tests with zero solver calls.
5. Only after prerequisites pass: preregister and execute one two-round window,
   <=4 actors per round, <=8 new native calls; independent continuation to goals.
6. Produce separate gate outcomes, logs, source hashes, portable verification,
   report and handoff. A failed map condition stops dependent stages per A4.

All normal stages write completion/failure events and durable logs. No commits,
historical writes, map changes or use of the independent DG002 C/L budget.
