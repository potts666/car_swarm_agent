# MA-DMPC-v1 实例方法（实现前）

先于代码和数值调用记录。物理、量化、数值设置及64维本车输入继承001；初始完整策略来自001规范化历史见证。进度η=.02m/拍，运动阈值1e-8m/拍。预先冻结δ={1,2,4,8}、beam宽4深2、每池最多16（含旧合同），池内按(-A,-P,B,J,ID)确定选择，源按绝对拍升序扫描，最终优先4其次3其次新增活动2。

从静止等待末端取已保存完整路线，删除等待并整体前移；保留已执行输入/权限。若原直线起步不足η，先保存限制，再以同一解析三点加速度校正守恒总冲量和一阶时矩，保持该直线连接的末端位姿/速度/轮角及原后续；不能满足物理界即拒绝。所有新联合尾段完整物理重放后，重建分离面beta与排他资源日历，并重算接收/K和期限。

每车进度图册来自真实已认证路线的直线/定曲率弧，含有向倒车。首两拍图册无歧义后把进度Taylor原行编译入本车问题。连续两拍配额绑定绝对时间，下一拍继承未完成义务。一般转接图册必须认证覆盖/唯一性，未建成部分不冒充有效活动。

真实源保持旧见证直到整个物理迁移事务通过，新合同内锚点单独保存，数值失败用新锚点，事务失败整块回旧合同及旧计划。所有修改面/资源/接收端点组成闭包。新界面生效后可拆回固定界面的独立事务，第二轮使用真实后继和真实尾段。

两臂并发C-new/L-new各两轮，每车每轮一次，最多16新调用；R-old零调用。报告物理锚点的活动收益和其上SOCP代价收益，不混淆。所有原失败、原始数值和独立全任务验收保留。

## 零调用共同接收器复用修订

初版为每个候选、每辆车重复完整联合后续几何重放。v2改为以已封存且完整重放的显式物理合同给出的本车Haussdorff预算为几何前提；N之后从本车有理中点参考只传播本车动力学，并用相同Ep/Et、A_g*r0及保存目标余量构造接收域。其他车在各自合同面内任意变化已经被完整契约覆盖，不再假装它们固定不动。所有nominal_*证书明确标明N之后只有actor字段是私有参考，不是实际未来联合状态。联合实际前缀、实际K、完整组合及独立8子段重放仍保留。

该修订不改变地图、模型、容差、配额、提案池、选中窗口或预算；原接收证据及完整源版本归档，全部登记源及不足配额/旧源回归在数值调用前重新通过。已完成的纯物理候选证书可按对象身份复用。
