## A 研究目标如何落到方法

优先探索3车、4车同时有效推进。车辆可等待、驶出、接近通道或倒车，各自优化实际加速度和转向速度。

同时记录三个数量：本轮求解车数、实际移动车数、沿任务连接有效推进车数。选定活动车的首拍进度条件进入本车MPC与完整认证。

上一轮用户报告验证了两车连续更新。本轮进一步改变物理边界或资源时段，让旧合同中保持的车辆获得推进动作。

## B 新合同从哪里来

```flow
当前状态与合法尾段 -> 车辆提出提前启动或连接请求
车辆提出提前启动或连接请求 -> 发现有关车对与资源
发现有关车对与资源 -> 形成局部协调事务
形成局部协调事务 -> 构造新锚点和物理合同
构造新锚点和物理合同 -> 认证净空与接收后续
认证净空与接收后续 -> 选择更大活动集合
选择更大活动集合 -> 各车独立求解并共同提交
```

静止等待段可尝试前移原运动输入。输入从相同静止状态起步，空间运动得以继承；新的绝对时刻需重新检查邻车与资源。

## C 理论增加了什么

每个有限提案池包含旧合同与原计划。先满足物理条件、接收后续及完成期限，再优先选择更多有效推进车。

$$
\max_{i\in D}\widehat b_i\le\max_{i\in D}b_i
$$

在已认证提案池中，选中的活动车数至少达到原计划。各块外部契约相容时，块内活动数最大值可组合。

新合同内独立优化使用同合同锚点回退。事务拒绝时整块沿用旧计划。真实首拍执行后移位尾段，全局期限仍逐拍下降。

$$
B_{k+1}\le\max(B_k-1,0)
$$
