# 两项后续工作的具体理论

日期：2026-11-14。版本CURVE-JOINT-v1 / LOCAL-FRAME-v1。本轮只推导与核对数学，未修改控制器或执行控制实验。

## 已完成的证明稿

### A：弯道加速度与转向速度联合优化

1. 从真实自行车ZOH得到显式积分、一阶变分与分段多项式矩。
2. 推导航向、位置和完整车角的二阶余项，以及连续时间弦误差。
3. 写出可直接进入SOCP的道路/车对/终端接收约束与允许步幅。
4. 以二阶差分方向精确保留末速/末轮角，消除一阶末端航向漂移。
5. 原输入代价下给出可检验改进条件；匀速圆弧零输入已有最小能量。
6. 对可选的“推进奖励+输入代价”，给出弯道上的联合严格改善定理与明确非零步幅例。
7. 将新候选接到真实尾段移位、接收域和多车安全组合的归纳。

A_弯道联合输入证明.md为完整正文，便携包中对应curve_theory.md。推进目标属于本稿的明确理论选项，当前控制工程目标保持原版本。

### B：两车小组的自然独立事务

定义对外固定占用包络、资源租约窗口、接收和期限承诺；内部计划可在其中变化。证明内层更改可只由有关小组认可，外组在原保证内继续执行或优化。

给出基于报告窗口[26,924)的两车候选，区分窗口算术已成立与地图几何/接收尚待具体认证。B_两车局部事务证明.md为正文，包中对应local_frame_theory.md。

## 具体认证流程

1. 读取实际弯道源与后续，计算V/D、输入矩、导数和每节点余项。
2. 检查固定curvature的实现等式与真实物理约束，形成真正开放a/omega的模型。
3. 为当前共同面、接收和后续求允许步幅；先检验旧目标的改善方向。
4. 若采用新推进目标，单独冻结其lambda/进度图册并按定理验证联合方向。
5. 实际外部帧先认证占用/资源/接收余量，再选择两车内部更新。

具体地图的输入、边界与接收常数仍需从真实工程计算。正文证明给定量条件、公式和构造，实例认证据此判定适用范围。

## 精确核对

symbolic_checks.py使用SymPy1.14.0，共12类检查，含Hessian、三块方向、正进度系数、终端矩及有理非零步幅证书。返回文件为symbolic_checks.json。

```bash
python3 symbolic_checks.py
```

当前Ubuntu若已有SymPy即可运行；本轮Windows核对依赖隔离在_symbolic_deps，未改变控制工程依赖。该依赖目录不随理论包分发。

这些检查核对公式与示例，不代替正文的模型类证明。source_notes.md附DOI与已有Zotero阅读位置。包内verify_package.py核对SHA，不需要SymPy，也不调用优化器。
