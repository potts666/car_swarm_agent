# dynamic_groups_001 方法（实现前记录）

依据 DG-DMPC-theory-v1。继承003名义有符号自行车、量化、区间算术与certificate_suboptimal_v1。初始完成策略来自旧有理路线构造，不声称在线搜索得到。

采用理论§3.4允许包络分离方案：基准完整轨迹的道路、六对净空及资源裕量，各车仅消费其四分之一；任意两车合计至多消耗一半净空。封存整条有限合同与本车源，接收/K及保留后续也须在同一包络中。动态编辑图连通分量形成组；固定物理边界时单车组独立提交。迁移保留全部六条边、输入、接收及逐车完成期限。

所有车辆共用generation.generate入口，64个本车增量与原辅助变量。目标h∑uᵀRu，R=diag(1,1)，三臂一致。原003锥目标除以其正比例scale后与该目标等价；数值配置不变。

本车数值失败使用本合同锚点；事务失败使用整块旧合同和旧计划。执行后从真实联合后继移位，b_i=max(goal_i-k,0)，块最大期限不得增加，B逐拍下降。

先认证构造条件、零锚点与正自由度后冻结首个连续两拍窗口，再允许12次调用；未满足前置条件禁止求解。实际结果与理论充分条件分别记录。
