## A 本轮推导回答什么

已写成一套条件明确的数学构造。理论面向一般车辆集合，四车地图用于下一步具体认证。

```flow LR
自行车与实际ZOH -> 连续车身契约
连续车身契约 -> 各车独立SOCP
各车独立SOCP -> 局部共同提交
局部共同提交 -> 同时执行首拍
同时执行首拍 -> 继承实际尾段
继承实际尾段 -> 各车独立SOCP
```

完整公式与证明见配套《完整推导.md》，第1—13节。

## B 同时改变计划，安全怎样组合

同一车对共享方向 $n$ 和边界 $\beta(t)$。两辆车各自遵守一侧约束。

$$
\max_{x\in B_i(t)}n^Tx\le\beta(t)-d/2
$$

$$
\min_{y\in B_j(t)}n^Ty\ge\beta(t)+d/2
$$

两式相减得到投影间隔至少为 $d$。固定单位方向下，车身欧氏净空也至少为 $d$。

有限节点加上段内弯曲误差包络，覆盖连续运动。每个潜在车对均纳入检查。接收域也按这些共同边界计算。

**定理一的核心：** 同合同内，任意允许局部计划的组合都安全。

$$
\prod_i\mathcal F_i(C)\subseteq\mathcal F_{joint}(C)
$$

## C 局部组怎样形成

先封存各车本轮允许变化的占用包络，再发现共享边界与资源依赖。

```flow LR
当前状态与允许包络 -> 交互发现
交互发现 -> 待修改边界图
待修改边界图 -> 连通分量形成协调组
协调组 -> 封存候选合同
封存候选合同 -> 各车同时求解
```

固定边界两侧的车辆可分别求解。需要改动共享边界的车辆共同协商。合并和拆分时携带输入、契约、接收后续与期限。

单通道核心资源保留排他占用，区域外允许多车同时运动。

## D 本车SOCP从哪里输入、输出什么

输入包括实际五状态、移位锚点、邻车契约、接收域、后续控制和期限。

本车优化未来32拍的加速度与转向速度增量。约束涵盖有符号速度、输入、转角、道路、分离面、权限和接收条件。

首版固定期限下，局部代价使用归一化输入平方积分。通行连接与期限提案在合同协商层评价。

```flow LR
实际状态与锚点 -> 导数及余项界
导数及余项界 -> 本车SOCP
本车SOCP -> 量化与原行重验
量化与原行重验 -> 连续车身及后续认证
连续车身及后续认证 -> 共同认可
```

## E 两种回退各自处理什么

```flow
候选合同内独立求解 -> {局部求解通过?}
{局部求解通过?} -> 本车新候选: 通过
{局部求解通过?} -> 同候选合同内锚点: 未通过
本车新候选 -> {事务共同提交通过?}
同候选合同内锚点 -> {事务共同提交通过?}
{事务共同提交通过?} -> 执行新合同组合: 通过
{事务共同提交通过?} --> 整个事务块保留旧合同与旧计划: 未通过
```

共享边界改变后，参与车辆要使用一致的合同版本。文中给出几何反例，解释混用旧计划与新合同的风险。

## F 递归可行如何闭合

**定理二：** 从已认可策略执行首拍后，实际尾段提供下一轮可行候选。

$$
\widetilde U_i=(U_{i,1},\ldots,U_{i,N-1},u_{i,cont}(Nh))
$$

末项取真实合法后续。车辆进入可保持目标后，再接零输入。

证明依次使用：实际ZOH后继、尾段移位、契约平移、接收域后续包含，以及合并和拆分时的候选迁移。

持续SOCP有解还需内近似保留这个移位锚点。第6、9节将这一条件单独写明。

## G 局部协商如何保证全局完成

每车保存一份实际可执行的完成策略，以及剩余完成拍数 $b_i$。

每个事务块接受新方案时，要求本块最大期限保持非增。不同事务块可独立处理。

$$
B_k=\max_i b_{i,k},\qquad B_k^+\le B_k
$$

执行一拍后：

$$
B_{k+1}=\max(B_k^+-1,0)
$$

**定理三：** 初始存在有限完成策略，且每轮有限协商后执行，则全部车辆至多 $B_0$ 拍完成。

该证明的起点是已构造的合法完成策略。初始策略的生成与认证需要明确记录。
