# 双车分散式 MPC 闭环实验

2026-10-09，同一 U 形双车交叉场景，Python / NumPy / SciPy。
这是项目扩展，不归属 Dolgov 论文的章节复现。

每车优化 4.8 s 控制视界，控制周期 0.4 s。用实测积分状态更新初值，
每次只执行第一步加速度/前轮转角。两车使用上一轮邻车预测；每个
预测包含共同仿真纪元 100 s 下的绝对时刻。无周期内的反复协商。
car_2 使用现有 Hybrid A* + S–T 参考（保留已有等待），car_1 使用原
横向路线与末端减速参考；两车控制均由 MPC 求解，参考不覆盖执行状态。

```bash
source /opt/ros/jazzy/setup.bash
python3 src/car_swarm_agent/test/decentralized_mpc.py
ctest --test-dir build/car_swarm_agent -R '^test_decentralized_mpc$' --output-on-failure
```

| 指标 | 本次运行 |
|---|---:|
| car_1 到达时间 | 20.8 s |
| car_2 到达时间 | 25.6 s |
| 最小采样矩形车身距离 | 0.161651 m |
| 求解次数 / 最终拒绝次数 | 128 / 0 |
| 单车求解平均 / P95 / 最大 | 85.7 / 285.1 / 460.3 ms |
| 两车顺序求解耗时超过 0.4 s 的周期数 | 3 |

到达要求位置误差小于 0.3 m、速度小于 0.05 m/s。距离包含每车
0.1 m 的车身外扩余量。邻车 SAT 间隙要求至少 0.08 m，静态 SAT
间隙至少 0.03 m。速度最大数值残差 7.11e-15 m/s；
其他执行采样约束违背为零，全部在 1e-5 容差内。

128 份求解记录独立检查了邻车时间戳来自上一轮、预测覆盖本轮
完整视界。测试另覆盖绝对时间插值、覆盖不足/时间戳错误拒绝、
预测尾段覆盖，以及静止邻车确实改变制动控制并保持车身间隙。
非凸求解采用居中差分；失败时记录一次制动初值重试，仍以最终
约束门槛决定是否执行。本次交叉场景没有触发重试。

本次运行摘要随代码保存为 `test/decentralized_mpc_summary.json`。
完整机器可读结果保存在 `log/decentralized_mpc/summary.json`、
`solves.json`、`predictions.jsonl`、`actual.csv`，初值导出在 `seed/`。
`solves.json` 包含每轮求解尝试、控制、邻车时间戳与逐项执行约束残差。
耗时依赖运行机器与负载；顺序求解有 3 轮超过控制周期，
此运行是按仿真时间推进的离线闭环，不能据此声称已经满足实时调度。

当前预测交换为进程内同步数据包，没有 ROS 传输、延迟/丢包实验、
同周期多轮协调或协同收敛规则，所以只称分散式 MPC 基线。
执行模型为独立 Python 中点自行车模型（0.1 s 子步），没有复用
原 C++ 积分器；转角变化率是离散命令差，未模拟转向执行器动态。
计划和执行都只做采样约束检查，没有连续时间安全结论。
S–T 已提供等待参考，本次结果不证明无等待参考时能自主解决死锁。
